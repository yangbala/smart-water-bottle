# 智慧照護科技平台：物聯網智慧水杯模擬系統

本網站結合了前端動態網頁技術（**Tailwind CSS**, **FontAwesome**, **Chart.js** 歷史圖表與 **Web Audio API** 音效合成器），打造出一個直覺且溫馨的照護科技平台。

## 核心功能模組

### 1. 智能水杯模擬器（實體互動）

* **外觀設計**：一隻具備 OLED 螢幕與 LED 動態光圈的 3D 質感水杯。
* **物理模擬**：
* 可倒入不同飲品（水、茶、咖啡、果汁）。
* 動態改變水杯液體顏色、容量高度、TDS 水質與溫度。
* 支援模擬「飲用」或「加熱」等物理操作。



### 2. 長輩飲水儀表板

* 結合**波浪動畫**的動態飲水進度環。
* 即時顯示今日總飲水量與目標達成率。

### 3. 照護端遠端互動

* 模擬子女/照護者的手機介面。
* 支援**跨螢幕互動**：可發送「關懷提醒語」與「震動呼叫」至水杯 OLED 螢幕，並同步播放溫馨提示音。

### 4. 健康數據分析與圖表

* 利用 **Chart.js** 繪製一週飲水走勢圖。
* 提供 AI 水分攝取狀態分析與個人化健康建議。

### 5. 療癒音效反饋

* 使用 **Web Audio API** 即時合成「注水聲」、「喝水聲」與「關懷蜂鳴聲」。
* **優勢**：免載入外部音檔，即可帶來極佳的即時互動體驗。

## 系統操作指南

### 📱 實體水杯操作模擬

* **飲水模擬**：點選水杯下方的 **「模擬喝一大口」** 或 **「模擬喝一小口」** 即可模擬長輩飲水。
* *連動反應*：水杯中的液體水位會動態下降、LED 發光圈閃爍、OLED 更新今日喝水量，同時中間的健康波浪環形圖與歷史圖表均會即時同步。


* **補水模擬**：當杯子空了時，點選 **「倒水 / 補充飲品」** 即可自由選擇飲品（綠茶、咖啡、溫開水、牛奶），並可透過拖拉滑動調整水溫和水量。
* *連動反應*：倒入茶、咖啡或牛奶時，水杯中液體的顏色和檢測到的水質 (TDS) 讀數均會發生相對應的動態變化。



### 💬 遠端子女照護模擬

右側設有「子女手機端 APP」模擬模組，完美重現「子女關懷與物聯網水杯」的雙向互動情境：

* **發送關懷**：可點選快速短語（例如：「該喝水囉！❤️」、「吃藥配水」）或在底下的輸入框寫入自訂文字並點選「發送」。
* **雙向反饋**：點選發送後，水杯會播放一段溫馨的**和弦提示音**，且水杯上的 **OLED 藍色螢幕** 會跳出跳動的紅色愛心訊息，伴隨著杯底 **LED 轉為粉紅色的浪漫呼吸燈**。

### 🎵 優美的即時合成音效

* 系統採用先進的 **Web Audio API** 聲學合成器。
* 當進行喝水、注水及發送關懷指令時，系統將即時產生清脆、滑音及和弦蜂鳴聲，帶給使用者絕佳的沈浸式感官回饋。
* *貼心設計*：可在右上角進行**一鍵靜音**切換。
